Skin Studio

The sheet is a 64×64 tile map in the standard block-game skin layout, so any skin editor or downloaded skin PNG works here. Pick a body part above to zoom in; the outlines mark each face. The "layer" parts (hair/hat, jacket, sleeves, pants) are drawn on top and can be see-through. Press V in game (or the eye button on mobile) to see yourself.

Mining Images

Use transparent PNGs. Cracks appear on the block you are breaking, stage by stage as the progress bar fills.

CRACK FRAMES

Import one strip (frames side by side, or stacked) or several images at once (sorted by file name). First frame = barely cracked, last = about to break. Any frame count from 1 to 32.

BREAK PARTICLE

One small image used for the chips that fly off. It is tinted with the block's colour, so a white or grey shape works for every block.
